Windows users :

Unzip the ZIP file, go into the "dogverse" folder, and look for "RPG_RT.exe". This is the game executable. Without it, there would be no game.


Windows - If you're updating from an older version :

You can move your saves from the old version to the new one.

  1. Download the new version from here.
  2. Go into the old version's game directory, and look for *.lsd files. These are your save files.
  3. Move all of the save files into the new version's game directory

If you did everything correctly, the newer version should be able to detect your old save files. Note : Your save may or may not carry over correctly. Don't say I didn't warn you.

Android users :

While it is not recommended, it is possible to play this game on Android.

  1. Download the ZIP file, but do not unzip it.

    2. There are two apps you can use. EasyRPG and RetroArch.

    EasyRPG Instructions

  2. Download EasyRPG from the Play Store, and set up EasyRPG first.
  3. Place the ZIP file in EasyRPG's "games" folder.

    4. RetroArch Instructions

  4. Place the ZIP file in a dedicated folder. (optional)
  5. Set up RetroArch first. Play around with the settings and theme. These instructions assume you have the XMB theme applied.
  6. Select "Online Updater", then select "Core Downloader". It should list "RPG Maker 2000/2003 (EasyRPG). Select it, and then download it.
  7. Go back to the main menu, and select "Load Core", then select the core you just downloaded.
  8. Confirm that you've selected the right core. It should say "RPG Maker 2000/2003 (EasyRPG) on the bottom left corner.
  9. Select "Load Content", and then navigate to where you saved the ZIP file. Once you've selected the ZIP file, select "Load Archive".
  10. You should see the EasyRPG splash screen, and then a menu. Optionally, select "Settings" to adjust EasyRPG to your liking. Select "Game", then "dogverse".

    11. You should be done. Please note this game was primarily intended for Windows, and uses the maniacs patch, which EasyRPG does not fully support at the moment.

    Android - MIDI soundfont issue :

    This game uses MIDI music files. On EasyRPG, they might not play without a soundfont. Here's a fix:

    1. Search for a MIDI soundfont. The default Windows soundfont is recommended, but really, any soundfont will do.
    2. You should now have a *.sf2 file. Place this file in EasyRPG's "soundfonts" folder.
    3. You're done.

    Android - Updating from an older version : 

    1. Refer to step 1 of the Android install instructions.
    2. Place the newly downloaded version's ZIP file into EasyRPG's "games" folder. (and run the game at least once for EasyRPG to create a saves directory for the new version)
    3. Go into your "saves" folder, look for the old version's directory, and look for any *.lsd files.
    4. Move all of these files into the new version's directory in the "saves" folder.

    If you did everything correctly, the new version should now pick up on your save files. Now you can play on the go on a fresh new version. Of course, who would really do that.
